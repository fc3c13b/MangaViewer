# MangaViewer

## AI 開発概要

MangaViewer は、Windows Forms を使用して開発されたマンガ（コミック）閲覧アプリケーションです。AI 技術を活用した機能強化を行っています。

- **フレームワーク**: .NET 8.0 (Windows Forms)
- **言語**: C#
- **IDE**: Visual Studio 2022
- **ターゲットプラットフォーム**: Windows

## 開発環境

以下は AI 関連の開発に必要な環境設定です。

### 必要なソフトウェア

- .NET SDK 8.0
- Visual Studio 2022
- Git
- Python (最新版)

### ライブラリ依存関係

- SkiaSharp: 画像デコード用
- OpenAI GPT API: AI 処理用

## コード構造と品質

MangaViewer のコードベースにはいくつかの問題点があります。以下の項目で改善予定です。

### Form1.cs のコード整理

- 現状、`Form1.cs` が非常に長く複雑なため、関連機能別にクラスを分離します。
- 主な機能は次のクラスとして分離されます：
  - `KeyboardInputHandler`: キーボード入力処理
  - `ImageService`: 画像読み込み・表示管理
  - `RatingService`: 評価値付与とキャッシュ管理

### コード品質向上

- エラーハンドリングの改善：`try-catch` ブロックを適切に配置し、詳細なログ出力を追加します。
- コメント追加：各クラス・メソッドには役割と使用方法のコメントを追加します。

### リファクタリング

- `SettingsManager.cs`: 設定値管理ロジックを抽出し、`Form1.cs` から分離します。
- `Constants.cs`: 定数をまとめて管理します。

### パフォーマンス改善

- スレッドセーフなキャッシュ仕様：画像読み込みと評価値保存の際にスレッドセーフにします。
- メモリリーク防止：不要なオブジェクトは適切にDisposeします。

### コードスタイルの統一

- インデントと命名規則を統一し、可読性向上します。NuGetパッケージ警告を解消します.
## インストール手順

```bash
# 1. .NET SDK 8.0 をインストールします
dotnet --version # バージョン確認

# 2. Visual Studio 2022 をインストールします
# 3. Git をインストールします

# 4. ソースコードをクローンします
git clone https://github.com/fc3c13b/MangaViewer.git
cd MangaViewer

# 5. 必要なパッケージをインストールします
dotnet restore
```

## 使用方法

```bash
# デバッグビルド実行
dotnet build -c Debug
dotnet run
```

またはビルド後の実行ファイルを直接起動してください。

### ショートカットキー一覧

| キー | 機能 |
|------|------|
| `1` (キー1) | フォルダ選択ダイアログを開く |
| `0` (キー0) | 設定ダイアログ表示 |
| `→` (右矢印) | 前の2ページに戻る（数字の小さい方へ） |
| `←` (左矢印) | 次の2ページに進む（数字の大きい方へ） |
| `↑` (上矢印) | 上位のフォルダ（前の話）へ移動 |
| `↓` (下矢印) | 下位のフォルダ（次の話）へ移動 |
